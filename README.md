
阅间 Yomi 是一款免费闭源的 Windows 本地漫画 + PDF 阅读器。

## 老板键

提前选好一份工作用的 PDF，设好返回密码。阅读漫画时按下老板键（默认 F9，可改），界面会切换到这份 PDF 并锁住漫画入口。

切换后应用就是一个正常的 PDF 阅读器。可以关掉当前文件、打开别的 PDF、关掉应用重新启动，都不会回到漫画界面。唯一的返回方式是进设置输入密码。验证成功后恢复切换前的漫画阅读场景。

老板键在应用内随时可以触发，优先于其他快捷键。首次使用前建议先跑一遍完整流程：设好 PDF 和密码 → 按老板键 → 输密码返回。

> 老板键仅在应用内生效，不是系统级防护。

## 漫画阅读

单页 / 双页布局、缩放、旋转、自定义操作方式。书架管理、书签、动人瞬间、回收站、隐私书架。

## PDF 阅读

目录、缩略图、文字搜索、书签、最近文档、独立阅读进度、缩放与旋转。切换后可以正常翻页和操作，不是停在一张截图上。

> PDF 层暂不支持打印、批注编辑、表单填写、数字签名、多标签和连续滚动。

## 下载

[前往下载页面 →](https://github.com/UQchdOliver/yomi-reader-releases/releases)
适用于 Windows 11 x64，需要 Microsoft WebView2 Runtime。

1. 下载本页附件中的压缩包。
2. 解压到一个新文件夹。
3. 运行 `yomi-manga-reader.exe`，不要删同目录下的其他文件。

不要在压缩包里直接运行。

## 数据说明

发行包不含任何漫画、PDF 或使用记录。应用数据保存在自身目录下，便携使用；新解压的副本不会自动读取旧版数据。

返回密码和隐私书架密码是独立的，属于应用内的访问控制，不是文件加密。
